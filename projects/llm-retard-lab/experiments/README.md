# Experiments

Your own research experiments that cross-pollinate ideas from courses and the shared library.

## Structure

Create a new directory for each experiment:

```
experiments/
├── 2026-05-06-lora-sft/
├── 2026-05-10-karpathy-wavenet-dpo/
└── README.md
```

Each experiment should include:
- `README.md` — Hypothesis, method, results
- `config.yaml` — Hyperparameters
- `notebook.ipynb` or `main.py` — Code
