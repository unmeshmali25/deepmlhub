# Karpathy: Neural Networks — Zero to Hero

Course-specific sandbox for Andrej Karpathy's [Neural Networks: Zero to Hero](https://karpathy.ai/zero-to-hero.html) series.

## Structure

- `notebooks/` — Lecture-by-lecture notebooks (added as you go)
- `scripts/` — Standalone scripts for each lecture (added as you go)
- `data/` — Course-specific datasets

## Notes

Code here is intentionally "from scratch" and educational. It may duplicate concepts from `llm_training` but should follow Karpathy's minimal style for learning.
